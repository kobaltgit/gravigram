## 🌟 Ключевые возможности

* ⚡ **Живой стриминг в Telegram**: Динамическое редактирование одного сообщения по ходу генерации ответа (`💭 Думаю...` $\to$ `🛠 Выполняю команду / инструмент` $\to$ `📝 Готовый форматированный ответ`).
* 💙 **Нативное приложение Flutter Mini App (TMA)**: Быстрый Material 3 SPA внутри Telegram (мобильные устройства, ПК, Web) для просмотра статуса агента, проводника файлов, истории диалогов и управления планировщиком.
* 🔑 **Переключение Google-аккаунтов в 1 клик**: Безопасное хранилище профилей, переключение без перезапуска бота и повторного входа, поддержка автоматического перехвата на `127.0.0.1:8085`, мобильный fallback и синхронизация с Windows Credential Manager.
* 🔒 **Строгая безопасность для одного владельца (Single-User)**: Принцип Fail-Closed. Доступ к боту, командам, файлам и API открыт исключительно для указанного `TELEGRAM_ADMIN_ID`. Посторонние пользователи отсекаются на уровне middleware.
* 🕒 **Автономный планировщик задач**: Запуск промптов агента по расписанию (ежедневно в заданное время или по cron-выражениям), автоматический учёт ошибок, история запусков и готовые шаблоны.
* 🎙 **100% Локальное распознавание голоса**: Локальный движок `faster-whisper` расшифровывает голосовые сообщения на процессоре или видеокарте без обращения к сторонним API и без утечки данных.
* 📄 **Анализ файлов и логов**: Приём документов, логов, скриптов и отчётов (`.py`, `.log`, `.txt`, `.json`, `.csv`, `.pdf`) прямо в чат для аудита, поиска ошибок и рефакторинга.
* 📦 **Отправка артефактов**: Новые скрипты, исправленные файлы и отчёты бот отправляет обратно в чат файлами-документами.
* 🛡 **Контроль автономии**: Переключение между полным автономным выполнением `/auto` (с флагом `--dangerously-skip-permissions`) и безопасным режимом `/confirm` (кнопки одобрения опасных shell-команд и правок).

## 🛠 Установка и запуск в 1 команду (All-in-One)

Проект поставляется как полностью автономный комплект. Вам не нужно вручную создавать виртуальные окружения или компилировать Flutter — скрипты установки берут всю рутину на себя.

### 🐧 Linux / VPS (Ubuntu, Debian, CentOS, Arch, macOS)

**Вариант А — Быстрая установка в 1 строку на чистом сервере (авто-клонирование и запуск):**
```bash
curl -fsSL https://raw.githubusercontent.com/kobaltgit/gravigram/main/install.sh | bash -s -- https://github.com/kobaltgit/gravigram.git
```

**Вариант Б — Клонирование вручную и запуск:**
```bash
git clone https://github.com/kobaltgit/gravigram.git
cd gravigram
bash install.sh
```

**Что скрипт делает автоматически:**
1. Если репозиторий ещё не склонирован — сам устанавливает `git` и клонирует проект по переданному адресу.
2. Устанавливает Python 3.10+, pip, venv, curl, tar, git и ffmpeg через системный пакетный менеджер (`apt`, `dnf`, `pacman`).
3. Создаёт виртуальное окружение `venv` и ставит Python-зависимости.
4. Находит существующий бинарник `agy` в системе или предлагает установить официальный CLI Antigravity.
5. Распаковывает готовый веб-бандл Mini App (Flutter SDK на сервере не требуется).
6. Запускает диалог настройки токена бота и ID администратора.
7. Настраивает обратный прокси Nginx с бесплатным SSL-сертификатом Let's Encrypt (Certbot).
8. Создаёт и включает фоновую службу systemd (`gravigram.service`).

---

### 🪟 Windows (Локальный ПК или сервер)

**Вариант А — Быстрая установка в 1 команду в консоли PowerShell:**
```powershell
irm https://raw.githubusercontent.com/kobaltgit/gravigram/main/install.ps1 | iex
```

**Вариант Б — Клонирование вручную и запуск:**
```powershell
git clone https://github.com/kobaltgit/gravigram.git
cd gravigram
powershell -ExecutionPolicy Bypass -File install.ps1
```

**Что скрипт делает автоматически:**
1. Проверяет наличие Python 3.10+ (при отсутствии сам ставит Python 3.11 через `winget`).
2. Создаёт `venv`, устанавливает библиотеки и распаковывает Mini App.
3. Находит `agy.exe` и связывает токены с Windows Credential Manager (`gemini:antigravity`).
4. Генерирует `.env` и разворачивает базу данных SQLite.
5. Создаёт удобные ярлыки запуска (`start_bot.bat`, `start_hidden.vbs`, `stop_bot.bat`).

## 🔑 Менеджер аккаунтов Google Antigravity

В проект встроен полноценный менеджер профилей ([`src/agent/accounts.py`](file:///d:/Projects/active/antigravity_bot/src/agent/accounts.py)):

1. **Изолированное хранилище**: Токены каждого аккаунта хранятся в `~/.gemini/accounts_vault/<email>.json`.
2. **Переключение в 1 клик**:
   * Нажмите **«🔑 Аккаунты»** на клавиатуре бота.
   * Текущий активный аккаунт отмечен: `✅ email@gmail.com`.
   * Нажмите кнопку `🔄 switch@gmail.com` — профиль переключится за **1 секунду** без перезагрузок и ввода паролей.
3. **Двусторонняя синхронизация (Windows & Linux)**:
   * **Linux / Сервер**: Мгновенно подменяет активный `oauth_creds.json` и файл `google_accounts.json`.
   * **Windows**: Синхронизирует как файл, так и системный Windows Credential Manager (`gemini:antigravity` через `Advapi32.dll`), благодаря чему `agy` в терминале и бот всегда работают под одинаковым профилем.
4. **Привязка новых аккаунтов**:
   * Нажмите `➕ Войти в новый аккаунт`.
   * **Локальный режим**: При открытии ссылки на том же компьютере фоновый loopback-приёмник на `127.0.0.1:8085` автоматически подхватит ответный токен.
   * **Мобильный режим**: При открытии со смартфона скопируйте адрес из адресной строки браузера (содержащий `code=...`) или сам код и отправьте сообщением боту в чат.

## 📱 Интерфейс Flutter Mini App (TMA)

Мини-приложение открывается кнопкой **«🚀 Open Mini App»** в Telegram или по настроенному HTTPS-домену:

* **Главная (Home)**: Индикатор статуса агента, активная модель, путь воркспейса, уровень автономии и метрики сервера в реальном времени (CPU, RAM, Диск).
* **Проекты (Projects)**: Проводник по каталогам, просмотр исходного кода с подсветкой синтаксиса и переключение рабочих папок.
* **Сессии (Sessions)**: Просмотр истории переписки с агентом, поиск по сообщениям и переключение бесед.
* **Планировщик (Tasks)**: Настройка задач с нативным TimePicker, пресеты в 1 клик (🌅 Утренний аудит, 🧪 Тесты, 🧹 Очистка) и журнал истории выполнений.
* **Настройки (Settings)**: Выбор модели ИИ, переключение автономии, политики подтверждения и параметров сервера.

## ⏰ Планировщик фоновых задач и автоматизация

Управление автозаданиями через CLI:

```bash
# Добавить ежедневную задачу в 09:00:
python -m src.agent.schedule_cli add --time "09:00" --title "Утренний аудит" --prompt "Проверь нагрузку, docker-контейнеры и место на диске"

# Посмотреть список задач:
python -m src.agent.schedule_cli list

# Поставить на паузу или включить:
python -m src.agent.schedule_cli toggle --id 1 --active true

# Удалить задачу:
python -m src.agent.schedule_cli delete --id 1
```

*Все результаты выполнения логируются в таблицу `task_runs` и отображаются в Mini App.*

## ⚙️ Конфигурация окружения (.env)

| Параметр | Обязателен | Назначение | Пример |
| :--- | :---: | :--- | :--- |
| `TELEGRAM_BOT_TOKEN` | **Да** | Токен бота от [@BotFather](https://t.me/botfather) | `8841318937:AAFP...` |
| `TELEGRAM_ADMIN_ID` | **Да** | Ваш числовой ID в Telegram (строгий single-user фильтр) | `123456789` |
| `DEFAULT_MODEL` | Нет | Модель Gemini по умолчанию | `gemini-3.7-flash` |
| `DEFAULT_WORKSPACE_PATH` | Нет | Начальная рабочая папка для агента | `.` или `/var/www` |
| `CONFIRM_MODE` | Нет | Запрашивать ли подтверждение опасных команд | `false` |
| `HOST` | Нет | IP-адрес для привязки веб-сервера | `0.0.0.0` |
| `PORT` | Нет | Порт веб-сервера FastAPI | `8000` |
| `WEBAPP_URL` | Нет | Публичный HTTPS URL для кнопки Mini App | `https://agy.yourdomain.com` |
| `AGY_BIN_PATH` | Нет | Точный путь к бинарнику `agy` при нестандартной установке | `/usr/local/bin/agy` |
| `TRUSTED_PROXIES` | Нет | Список доверенных IP обратных прокси через запятую | `127.0.0.1,::1,192.168.5.128` |

## 🧪 Автоматизированное тестирование

Gravigram снабжён полноценным набором автоматизированных тестов для асинхронного Python-бэкенда и фронтенда Flutter Mini App с **100% успешным прохождением (75 из 75 тестов)**:

* **Python Backend** (`pytest`): 64 теста, проверяющих CRUD SQLite, криптографическую валидацию Telegram TMA HMAC-SHA256, REST эндпоинты, планировщик `HH:MM` и cron, стриминг и хуки агента, паритет словарей переводов i18n RU/EN, валидацию и локализацию мастера установки, и менеджер аккаунтов Google OAuth.
* **Flutter Mini App** (`flutter test`): 11 тестов, проверяющих модели данных, реактивный `LanguageController`, строковую локализацию и виджет-тесты всех экранов (`HomeScreen`, `SettingsScreen`, `ProjectsScreen`, `TasksScreen`).

Запуск всех тестов в одну команду:

```powershell
# Windows PowerShell:
.\scripts\run_tests.ps1
```

```bash
# Linux / macOS Bash:
bash scripts/run_tests.sh
```

Или по отдельности:
```bash
# Тесты бэкенда:
pytest -v

# Тесты Flutter Mini App:
cd frontend_flutter && flutter test
```
